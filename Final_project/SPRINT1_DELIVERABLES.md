## 1. 專案執行摘要 (Executive Summary)

本專案旨在將傳統技術部落格（基於 Wagtail / Django）升級為**具備上下文感知、多工具調用、付費安全防禦與狀態化個人輔助**的自主共讀代理系統（Reading Co-Pilot Agent）。

相較於業界常見的「浮動聊天視窗（Floating ChatGPT Wrapper）」，本系統深入整合既有部落格的權限系統、文章資料庫、瀏覽歷程與會員計費點數體系，打造真正具備**事實溯源（Fact Grounding）與商業邊界防禦**的實用級 AI 代理。

## 3. 深入實作的核心功能 (What Features Are Built Deeply)

1. **付費感知與對抗防禦（Paywall-Aware RAG & Security）—— 專案最大差異化亮點**
   - **檢索層物理脫敏**：非會員發起查詢時，後端檢索模組直接過濾並將付費切片替換為脫敏摘要，付費正文根本不上傳至 LLM Context。
   - **對抗評測驗證 (6/6, 100%)**：成功防禦「請 verbatim 輸出付費正文」、「給我線性迴歸代碼與 MSE」等惡意 Probe，零洩漏同時合規引導訂閱。
2. **混合檢索與事實溯源（Hybrid Retrieval & Inline Tracing）**
   - 結合 Wagtail BM25 全文檢索與向量餘弦相似度空間，並在生成解答時自動將真實文章 URL 轉換為可點擊超連結。
3. **狀態化個人輔助與確認型工具調用（Stateful Personalization & Safe Actions）**
   - 深度整合 `BrowsingHistory` 瀏覽足跡模型，支援記住上次閱讀段落。
   - 書籤管理與評論草稿生成嚴格落實 `Pending Action` 雙階段確認，杜絕未授權副作用。

## 4. 專案邊界與明確限制：技術能力與時間約束 (Explicit Constraints & Boundaries)

我們誠實界定 Sprint 1 系統的能力邊界，明確說明哪些功能不做，以及背後的真實原因：

| 限制項目 | 約束屬性 | 原因說明與 Sprint 1 替代因應策略 |
| :--- | :--- | :--- |
| **1. 自動知識圖譜拓撲推理** | **技術難度 + 時間限制** | 原構想使用 Neo4j 自動抽取實體與計算前置知識拓撲排序。但在 4 週 Sprint 內，知識抽取對齊難度極高且容易產生錯誤邊。Sprint 1 改為使用專家結構化 JSON 學習地圖，由 Agent 動態選取推薦。 |
| **2. 非同步背景推播與定時郵件** | **架構簡約 + 成本限制** | 每日郵件提醒讀者需要常駐 Celery + Redis Worker 叢集，會增加架構複雜度並打破 Render Serverless 零維護成本環境。Sprint 1 限縮為「在線即時主動提示（讀者登入/打開側邊欄時即時關懷）」。 |
| **3. 本地大參數視覺模型推理** | **本地硬體算力瓶頸** | 本地開發機 GPU 無法並發流暢運算 70B+ 多模態模型，且即時生圖延遲過長（>15秒）。Sprint 1 全面接軌 Cloudflare Workers AI 32B 雲端 API，保持秒級響應。 |
| **4. 真實第三方金融金流清算** | **法規審核週期** | 串接真實 Stripe/銀行支付需要跨國企業實名與牌照審核，超出學期專案範疇。Sprint 1 採用虛擬積分帳本與訂閱狀態模擬，完整支撐商業權限驗證。 |

## 5. 最重要：如何評估與實驗數據 (Evaluation Methodology & Empirical Results)

### 5.1 評測架構（33 項確定性任務）
以 `eval_tasks.json` 為核心，包含 33 項具備嚴格預期目標（Gold Answer / Target Behaviors）的基準任務，涵蓋 6 大維度：
- **Factual QA (6 題)**：檢驗對事實的精準問答與防幻覺。
- **Cross-article (5 題)**：檢驗跨多篇文章聚合知識能力。
- **Recommend Path (6 題)**：檢驗學習路徑與順序引導。
- **Continue Reading (5 題)**：檢驗對歷史瀏覽紀錄的感知。
- **Action (5 題)**：檢驗書籤增刪與雙階段確認。
- **Adversarial (6 題)**：檢驗付費牆防窺與提示詞越獄防禦。

### 5.2 四大基準系統對比實驗數據
在完全相同的 33 項評測任務下，實測四種系統變體的通過率階梯：

```

      │                                                ┌────────┐

      │                                       ┌────────┤  26/33 │
  60% ┼───────────────────────────────────────┤ 51.5%  │        │
      │                                       │  17/33 │        │
  40% ┼──────────────────────────────┬────────┤        │        │
      │                     ┌────────┤ 21.2%  │        │        │
  20% ┼────────────┌────────┤ 15.2%  │  7/33  │        │        │
      │            │  5/33  │        │        │        │        │
   0% ┴────────────┴────────┴────────┴────────┴────────┴────────┴──
                 Baseline A Baseline B Baseline C  Full Agent
                 (純LLM閉卷) (關鍵字搜尋) (傳統RAG) (雲端完整代理)
```

- **Baseline A (純 LLM 閉卷)**: 15.2% (5/33) —— 無站內知識，嚴重幻覺。
- **Baseline B (關鍵字檢索 + LLM)**: 21.2% (7/33) —— 僅能命中字面完全一致的單詞。
- **Baseline C (傳統 Naive RAG)**: 51.5% (17/33) —— 有檢索能力，但對抗測試中**嚴重洩漏付費文章**。
- **Full Agent (Cloudflare 32B 雲端)**: **78.8% (26/33)** —— 對抗測試 100% 通過，跨篇檢索 100% 通過，全面領先所有對照組。
